shop-ai - Sales flow (Workshop 5.4)

Cart, order placement, asynchronous order processing and admin order management. Press a numbered flow to walk its arrows; click a component for its role.

Email is sent only when the stack is deployed with senderEmail; the DLQ alarm exists in prod only.

Flow steps
  1. Sign in. The browser signs in to the Cognito user pool with SRP (TOTP MFA when enabled) and receives a JWT.
  2. API request. Calls go over HTTPS to CloudFront, which forwards /api/* to the HTTP API; API Gateway checks the JWT.
  3. Cart. Lambda cart reads and writes the carts table with a version check.
  4. Place order. Lambda ordering writes stock, order and cart in one TransactWriteItems, keyed by Idempotency-Key, then sends the order to SQS.
  5. Process order. Lambda order-processor marks the order CONFIRMED, emails the customer through SES and publishes order-confirmed to SNS.
  6. Failures to DLQ. A message that fails 3 times moves to the dead-letter queue instead of being lost.
  7. Admin. Lambda ordering-admin reads the byStatus index and moves orders through SHIPPED and DELIVERED, or cancels them.
