## Cập nhật trang

- Nội dung nằm trong `content/`: mỗi trang có `_index.vi.md` (tiếng Việt) và `_index.md` (tiếng Anh).
- Push lên nhánh `main` thì GitHub Actions (`.github/workflows/hugo.yml`) tự build và đăng lên GitHub Pages, khoảng 1 phút.
- Xem trước trên máy (cần Hugo extended 0.134.3):

```bash
hugo server
```

Rồi mở http://localhost:1313/
